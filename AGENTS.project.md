# Pitchline project instructions

- Canonical app framework is Next.js App Router.
- Preserve the warm paper background, navy primary, Fraunces display type, Outfit body type, spacing and card styling.
- Keep 1,000 deterministic Monte Carlo draws for scoreline distributions; use analytical grid probabilities for headline markets.
- Never claim historical validation without point-in-time pre-match inputs.
- Never invent xG/xGA or bookmaker odds; use source-attributed data only.
- Firebase Admin credentials and subscription writes are server-only. Never trust browser-supplied Pro status.
- Work on feature branches and open PRs; do not push directly to main.
- Never commit secrets or service-account JSON.
